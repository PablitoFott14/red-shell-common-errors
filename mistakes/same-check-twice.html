The same check written twice

costs points
Rubric Criteria - Overall Rubric Quality
1

What the issue is

Two criteria decided by the same piece of evidence: one fully swallowed by a broader one earlier in the set, a negative that is a positive with the sign flipped, or a subjective criterion restating an objective value check with a presentation layer on top.

2

Why it matters, and what the project expects

Redundant criteria double weight one outcome, so a single slip costs the run twice. A subjective block that repeats objective values also stops doing its own job, which is grading how the artifact reads and looks.

QC spec appendixRubric Quality Definitions · Overlapping/Redundant Criteria
Criterion that is either completely redundant because other criteria completely encompass the former or multiple criteria that check for the same thing partly. This can also apply to criteria which have direct semantic overlap with oppositely weighted criteria.

A negative that is a positive with the sign flipped counts here too.

QC spec appendixRubric Quality Definitions · Block Bleed
A deterministic value check placed in the subjective block, or a presentation judgment placed in the objective block. Count each misplaced criterion. The fix is to move it, never to duplicate it across both blocks.

A subjective criterion restating an objective value is this, not a second opinion.

3

How to recognise it in your own task

For each criterion, name the one line of evidence that decides it. If another criterion is decided by the same line, you have a duplicate. A subjective criterion has to survive with its values stripped out. If nothing is left, it belonged in the objective block.

4

Real tasks where this happened

One real task in this project is carrying it. It is evidence that it is real and something to practise spotting it on, not a second version of the rule. Open it and it expands here, with the point on the left and the task's own fields on the right. Escape closes it.

5

What to do instead

Keep one and drop the other. Where one swallows the other, keep the broader. A subjective criterion that restates an objective value keeps only its presentation property, or goes.

Anselm Kirchner (graphics editor, The Richmond Beacon) needs a year-in-review page of the desk's chart dailies. Nadine Ptaszek asked for something the desk can actually use. He wants it built from exports in the drop, path matches, and not from every chart…

The issue, in this task
The setup
The page carries an index of the four pieces that ran as dailies. Two separate criteria grade what is on that index.
Where the issue shows up here
Criterion 2: In years_in_review.html, the dailies index lists only 2026-02_export_0224.svg, 2026-03_frame_0305.svg, 2026-04_frame_0416.png and 2026-06_export_0611.svg. Criterion 9: In years_in_review.html, inspections_map_q3.png and inspections_church_hill.png are not listed on the dailies index.
Why that is wrong
If criterion 2 passes, criterion 9 cannot fail: the two maps are absent from the index precisely because the index lists only those four files. One page property carries two rows of weight, and criterion 11's second sentence says it a third time.
What it should have said
Keep criterion 2 and drop criterion 9. Cut the second sentence of criterion 11 too, so it grades only the click through: In years_in_review.html, every headline count clicks through to the files that make it up.

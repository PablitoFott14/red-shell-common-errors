2.1A Leg B hint that hands Model B the answer

Fails the taskMulti-Turn - Simulator Answer Leak

The mistake

In Leg B, a turn you send Model B hands it what it had to work out: a value, a count, a position or the conclusion. Naming the exact file to open costs points instead.

Do this instead

Hint as the user would: say what looks wrong and point at the area, never at the file, the value or the conclusion. If Model B still misses, hint again at the same level.

Leg A only. A punctual correction that comes up naturally is still fine, as long as it does not compromise the 50% failure threshold.

Each follow-up must do real work: deliver a withheld asset, extend a requirement, correct an error, tighten a constraint, or answer a clarification the agent asked for.

About the Leg A follow ups.

Why it matters

The no leak rule covers every turn you type in Leg B, exactly as in Leg A, and a leak fails the task however late it comes. A golden that meets a criterion because Model B was told the answer no longer shows the reasoning the criterion grades, and a hint that settles what one of your negatives exists to test tells Model B how to avoid the trap. What differs from Leg A is what a turn is for: a Leg B hint says what is still missing, while in Leg A a punctual correction is fine when it comes up naturally, as long as it does not compromise the 50% failure threshold.

All mistakes · Section 5 · Criteria a correct run can pass

Category and Evaluation Target filled with the wrong kind of value

costs points
Rubric Criteria - Overall Rubric Quality
1

What the issue is

The Category does not match what the criterion grades, or the Evaluation Target does not match where the grader reads it. Three shapes recur: a category name written into the target field, an Agent Behavior or Tool Use criterion pointed at the artifact, and a subjective criterion tagged Instruction Following.

2

Why it matters, and what the project expects

Category says what kind of check it is; target says where the grader looks. Both go to the client with the rubric data, so a wrong pair is wrong data even when the criterion is right. Agent Behavior and Tool Use grade how the run got there, so they sit on Trajectory: one pointed at a file, a state change or the final message is grading the deliverable and needs the deliverable's category. In the subjective block Task Completion is the only valid category, because anything the prompt explicitly asked for belongs in the objective block by definition.

Attempter Guidelines5.4 Category & Evaluation Target
Agent Behavior, Target: Trajectory, always. If you wrote Agent Behavior against an artifact, a state change or the final message, you picked the wrong category: you are grading the deliverable, which is Task Completion, Instruction Following or Factuality. This is the single highest value rule in the taxonomy, and it is the reviewer's standard audit query.

The highest value rule in the taxonomy. When Agent Behavior points at the deliverable, the target is right and the category is wrong.

Attempter Guidelines5.4 Category & Evaluation Target
Evaluation Target - Mechanical Assignment. A file the agent created or modified: Final Answer Artifact. The service, through snapshots.json: State Change. The final assistant message: User-Facing Message. The agent's reasoning path: Trajectory.

Target is mechanical: it is decided by where the grader looks, not by what the criterion is about.

Attempter Guidelines8.4 Categories and Evaluation Targets for Subjective Rubrics
Task Completion is the only valid category for subjective rubrics. Instruction Following is excluded by design, not by preference: if a requirement is explicitly stated in the prompt, it belongs in the objective block.

Subjective plus Instruction Following is a contradiction in terms.

3

How to recognise it in your own task

Filter by target and read the categories beside it. Agent Behavior and Tool Use always sit on Trajectory. Everything graded on the delivered file sits on Final Answer Artifact. Every subjective row is Task Completion.

4

Real tasks where this happened

Two real tasks in this project are carrying it. They are evidence that it is real and something to practise spotting it on, not a second version of the rule. Open one and it expands here, with the point on the left and the task's own fields on the right. Escape closes it.

5

What to do instead

Retag, do not rewrite. Set the target from where the grader looks, then the category from what the check is. Agent Behavior or Tool Use on a file keeps its target and becomes Task Completion, or Instruction Following when it checks a constraint the user set. A subjective row tagged Instruction Following is either a presentation property, so Task Completion, or an explicit ask, which moves to the objective block.

5.3Category and Evaluation Target filled with the wrong kind of value

Costs pointsRubric Criteria - Overall Rubric Quality

The mistake

Category or Evaluation Target does not fit the criterion: Agent Behavior or Tool Use on an artifact, a category in the target field, or a subjective row tagged Instruction Following.

Do this instead

Retag, do not rewrite: a check on a file takes the deliverable's category, and an explicit ask moves from the subjective block to the objective one.

Catch it in your own task

Read each category beside its target: Agent Behavior and Tool Use only on Trajectory, every subjective row Task Completion.

Where the correct guidance is written

Section titles as they print, so you can search for them in the document.

Guidelines · 5.4 Category & Evaluation Target

Agent Behavior, Target: Trajectory, always. If you wrote Agent Behavior against an artifact, a state change or the final message, you picked the wrong category: you are grading the deliverable, which is Task Completion, Instruction Following or Factuality.

Guidelines · 8.4 Categories and Evaluation Targets for Subjective Rubrics

Task Completion is the only valid category for subjective rubrics.
Why it matters

Category says what kind of check it is; target says where the grader looks. Both go to the client with the rubric data, so a wrong pair is wrong data even when the criterion is right. Agent Behavior and Tool Use grade how the run got there, so they sit on Trajectory: one pointed at a file, a state change or the final message is grading the deliverable and needs the deliverable's category. In the subjective block Task Completion is the only valid category, because anything the prompt explicitly asked for belongs in the objective block by definition.

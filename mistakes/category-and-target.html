Category and Evaluation Target filled with the wrong kind of value

costs points
Rubric Criteria - Overall Rubric Quality

What the mistake is

The two classification fields do not say what they are for. Three shapes recur: a category name written into the target field, an Agent Behavior or Tool Use criterion pointed at the artifact, and a subjective criterion tagged Instruction Following.

How to recognise it in your own task

Filter by target and read the categories beside it. Agent Behavior and Tool Use always sit on Trajectory. Everything graded on the delivered file sits on Final Answer Artifact. Every subjective row is Task Completion.

What to do instead

Fill the two as a pair and check them together in one pass before submitting. It is a sort and a scan, not a rewrite.

Why it costs you

Category says what kind of check it is; target says which part of the run it is read against. Filled wrongly they stop being checkable, and the pairing rules go with them. Agent Behavior and Tool Use grade the trajectory, so a criterion tagged that way against the artifact is graded in the wrong place. In the subjective block Task Completion is the only valid category, because anything the prompt explicitly asked for belongs in the objective block by definition.

What the project says

The rules this breaks, quoted from the documents in Project Resources. Section titles are the ones printed in the document, so you can go and read the whole thing around them.

Attempter Guidelines5.4 Category & Evaluation Target
Agent Behavior — Target: Trajectory, always. If you wrote Agent Behavior against an artifact, a state change or the final message, you picked the wrong category: you are grading the deliverable, which is Task Completion, Instruction Following or Factuality. This is the single highest value rule in the taxonomy, and it is the reviewer's standard audit query.

The spec says outright that reviewers query for this pairing.

Attempter Guidelines5.4 Category & Evaluation Target
Evaluation Target - Mechanical Assignment. A file the agent created or modified: Final Answer Artifact. The service, through snapshots.json: State Change. The final assistant message: User-Facing Message. The agent's reasoning path: Trajectory.

Target is mechanical: it is decided by where the grader looks, not by what the criterion is about.

Attempter Guidelines8.4 Categories and Evaluation Targets for Subjective Rubrics
Task Completion is the only valid category for subjective rubrics. Instruction Following is excluded by design, not by preference: if a requirement is explicitly stated in the prompt, it belongs in the objective block.

Subjective plus Instruction Following is a contradiction in terms.

2.3A deferred asset that announces its own turn

Fails the taskInput Artifacts - Deferred Asset Handling

The mistake

Something in the input folder, open to both models from turn 1, previews a later turn: a file named for its turn, or a document carrying a later instruction. A file named only for its contents costs points.

Do this instead

Name deferred files as a phone or scanner would, and let the Leg A follow up that delivers each one say what it is; the Leg B turn repeats it.

Why it matters

A deferred asset tests whether each model can take in new evidence mid conversation: Model A at its Leg A turn, Model B at its Leg B turn. Told in advance that a file is coming and what it is for, either model can prepare, and the later turn no longer tests it. A filename or document that previews the later turn's purpose or requirement fails the task; a name that only says what the file holds costs points.

What the mistake is

Five mechanical checks, each cheap, each seen repeatedly. The artifacts archive holding files the prompts never asked for — the generator script, working notes, a build log. No preferred run starred when several completed. A file spelled one way in the prompt and another in the archive. Typos and half-finished clauses in the prompts and criteria a grader has to decode. And a golden conversation that stops before the task's last turn.

How to recognise it in your own task

Five lists, side by side, in five minutes. Archive contents against the filenames the prompts name. The run picker reading 1/1 and not 0/1. Every filename character for character. The prompts and criteria read straight through as a grader would. User markers in the golden transcript against populated prompts.

What to do instead

Remove anything from the archive that is not a named deliverable, then read each delivered document for build instructions meant for you rather than the reader. Star the run your criteria were written against. The prompt's spelling wins — fix the archive to match it.

Why it costs you

Trajectory Exclusion is scored against the artifacts listing: finished artifacts only, named exactly as the prompts name them, nothing describing how the work was produced. A generator script is the clearest case, because its comments usually say which input each answer came from. An unstarred run leaves whoever opens the task next with only a timestamp, and a later run is not automatically the better one. A criterion citing a filename the archive does not contain is ungradeable. And a grader who has to work out what a clause means is making the judgment the clause was supposed to make.

What the project says

The rules this breaks, quoted from the documents in Project Resources. Section titles are the ones printed in the document, so you can go and read the whole thing around them.

Narration: text that describes the making of the artifact: which tools were run, what was tried, what got fixed, in what order.

QC specGolden Solution - Trajectory Exclusion
Caveat: text about the state of the deliverable: a source was unreadable, coverage is partial, a value is estimated, some rows are unverified. It tells the reader what they need to know to use the file correctly, and reveals nothing about how the work was done. Caveats in the content also do not count toward leakage.

So a note saying two rows are unverified stays. A note saying how you got them out does not.

Why it is wrong

What it should have said
"The delivery fee shown is $0.00." "...the eggs verdict for the Mon 6 Jul 2026 order." Read the milestone and rubric files end to end once before submitting, out of the editor they were written in.

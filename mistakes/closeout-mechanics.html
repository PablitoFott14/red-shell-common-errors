The five minute close out nobody runs

fails the task
Golden Solution - Trajectory Exclusion · Golden Solution - Artifact Completeness · Trajectory - Golden/Preferred Run Selection
1

What the issue is

Five mechanical checks, each cheap, each seen repeatedly. The artifacts archive holding files the prompts never asked for: the generator script, working notes, a build log. No preferred run starred when several completed. A file spelled one way in the prompt and another in the archive. Typos and half finished clauses in the prompts, milestones and criteria that a grader has to decode. And a golden conversation that stops before the task's last turn.

2

Why it matters, and what the project expects

Trajectory Exclusion is scored on the golden folder: finished artifacts only, nothing describing how the work was produced. Artifact Completeness wants every file the prompts name present and spelled exactly as the prompts spell it, and a golden that stops before the last turn is missing whatever the later turns asked for. A criterion citing a filename that no archive contains cannot be graded. A missing star costs points on its own and leaves whoever opens the task next with only a timestamp to choose by, and a later run is not automatically the better one. And a grader who has to work out what a clause means is making the judgment the clause was supposed to make.

QC specGolden Solution - Trajectory Exclusion
golden/ ships finished artifacts only. The external judge receives the golden ARTIFACTS and never the golden trajectory — anything left in the folder describing how the answer was reached leaks the solution path into grading. Narration: text that describes the making of the artifact: which tools were run, what was tried, what got fixed, in what order.

A generator script is the clearest case: its comments usually say which input each answer came from.

QC specGolden Solution - Trajectory Exclusion
Caveat: text about the state of the deliverable: a source was unreadable, coverage is partial, a value is estimated, some rows are unverified. It tells the reader what they need to know to use the file correctly, and reveals nothing about how the work was done. Caveats in the content also do not count toward leakage.

So a note saying two rows are unverified stays. A note saying how you got them out does not.

The preferred run (if multiple exist) must still be marked as ‘Preferred‘ with the star.

This holds on Leg B too: with several finished runs and none starred, nothing marks which one is the golden.

Attempter Guidelines7. Golden Solution - Leg B
Satisfies every objective requirement, with every required file present and named exactly as requested.

The prompt's spelling wins, and every file a later turn asks for has to be there, which it cannot be if the golden stopped early.

3

How to recognise it in your own task

Five checks, in five minutes. The artifacts archive listed beside the filenames the prompts name. The run picker, which should read “Preferred: 1/1 selected”, not 0/1. Every filename in the prompts, both archives and the criteria, read character for character. The prompts, milestones and criteria read straight through as a grader would, marking every clause you had to read twice. The golden transcript, which should carry every prompt the task ships, the last one included.

4

Real tasks where this happened

Three real tasks in this project are carrying it. They are evidence that it is real and something to practise spotting it on, not a second version of the rule. Open one and it expands here, with the point on the left and the task's own fields on the right. Escape closes it.

5

What to do instead

Remove anything from the archive that is not a named deliverable. If a delivered document carries build instructions meant for you rather than the reader, get them out with a cleanup turn in the user's voice before you complete the conversation. Star the golden run, the one whose artifacts you ship. The prompt's spelling wins, so fix the archive to match it. Rewrite every clause you had to read twice. If the golden transcript stops short, run every prompt on Leg B and export again.

The resident of Apt 4B at 123 Main street, San Francisco organizes the buildings shared Amazon Fresh group order for four apartments (2A, 3C, 4B, and 5D). A neighbor, Tom from 3C, mocked up a pantry board of product listings for the neighbors, and residents…

The issue, in this task
The setup
The rules file sets a delivery fee that falls away above a subtotal threshold, and the order date is established in criterion 3 as Monday 6 July 2026.
Where the issue shows up here
Criterion 22 asks for a delivery fee of "%0.00". Criterion 7 dates the eggs listing "for the Mon Jul 2026 order", with no day. Milestone 4 ends "an apartment the sheet doe snot marks keeps all the requests"; milestone 5 has "that apartment's quantity for the subscribes item is adjustment as the rules file says".
Why that is wrong
A percent sign where the dollar sign belongs and a date with no day leave the grader to find the intended value somewhere else in the set before either criterion can be applied. The milestone text is what the simulator replays, so the continuation check is made against a sentence that does not parse.
What it should have said
"pantry_audit.html shows a delivery fee of $0.00 for the Mon 6 Jul 2026 order." "...the eggs verdict for the Mon 6 Jul 2026 order." "...an apartment the sheet does not mark keeps all its requests." Read the milestone and rubric files end to end once before submitting, out of the editor they were written in.

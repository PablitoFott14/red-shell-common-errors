All mistakes · Section 4 · A rubric that separates two runs

A rubric that can only reward, never penalise

fails the taskMost common right now
Rubric Criteria - Overall Rubric Quality

What the mistake is

No negative-weight criteria at all, or so few that the traps the scenario was built around go unscored. Every criterion checks something correct is present; nothing checks something wrong is absent, so the traps the scenario was built around cost a run nothing.

How to recognise it in your own task

Count them. Negatives should be about a quarter of the set. Then check the sign is doing what you think: a negative criterion is a failure when it is Present, so if it reads like something a good run does, it is inverted and it will mark down your own golden.

What to do instead

After the Leg A run, read its trajectory for the wrong turns it actually took and write a negative for each one worth catching. State the flaw, never the virtue. Do not invent them to reach a number — but a scenario with no writable negatives usually means the traps are not there.

Why it costs you

A scenario earns its difficulty from the wrong answers sitting next to the right ones: the superseded quote, the decoy invoice, the figure from a different part of the store. Without negatives the rubric cannot see any of them, so a run that walks into every trap and recovers scores the same as one that never went near a trap. They are also the cheapest criteria to write, because Leg A usually shows you which failure to write about.

What the project says

The rules this breaks, quoted from the documents in Project Resources. Section titles are the ones printed in the document, so you can go and read the whole thing around them.

Attempter Guidelines5.3 Positive and Negative Distribution
Negatives are the exception: They should usually make up around 25% of the rubric block and should generally stay below 30%. Use a negative criterion only when it captures a specific, plausible failure mode that the scenario or trajectory meaningfully exposes.

About a quarter. Zero is as far off the mark as half.

Attempter Guidelines5.2 Rubric Weights
Rare but damaging is not a −5. A model leaking a password is rare, so inflating the weight misrepresents difficulty. The negative slots are for attractive wrong paths the model has to resist.

Negatives are priced on how tempting the wrong path is: tempting is −3, actively invited is −5.

A negative criteria penalizes something absent from the response instead of rewarding an equivalent thing being present. Example: “The response does not do ABC” weighted as −1, −3, or −5.

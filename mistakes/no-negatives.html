4.1A rubric that can only reward, never penalise

Costs pointsRubric Criteria - Overall Rubric QualityMost common right now

The mistake

Too few negatives for the scenario's traps, so taking the bait costs nothing extra, or a negative worded as the virtue, which marks down correct runs.

Do this instead

After Leg A, write a negative for each worthwhile wrong turn Model A took, stating the flaw, never the virtue.

Catch it in your own task

Negatives should be about a quarter of the set. Present means failure, so a negative describing a good run is inverted.

Why it matters

A scenario earns its difficulty from the wrong answers sitting next to the right ones: the superseded quote, the decoy invoice, the figure from a different part of the store. Without negatives the rubric cannot see any of them, so a run that walks into every trap and recovers scores the same as one that never went near a trap. They are also the cheapest criteria to write, because Leg A usually shows you which failure to write about.

4.5A run that does not fail enough of the rubric

Fails the taskHard Client Requirements for Every Task

The mistake

The criteria Model A fails carry under half the rubric's weight, both blocks counted. Everything looks sound; only the arithmetic shows it.

Do this instead

Under 50%, make the scenario harder and run both legs again. Never inflate the weights or pad the set.

Catch it in your own task

Divide the weight of the criteria Model A fails by the total, both blocks counted, signs ignored.

Where the correct guidance is written

Section titles as they print, so you can search for them in the document.

Guidelines · Hard Client Requirements for Every Task

Model A has to fail: Enough difficulty that the Model A trajectory clearly fails at least 50% of the final rubric score

Guidelines · 8.5 Rating Against both Models and Justifications

Rate each subjective rubric as Present or Not Present for Model A.

So the 50% counts both blocks.

Why it matters

Every task has to be hard enough that the Model A trajectory clearly fails at least 50% of the rubric score. That is a hard client requirement, not a target. A run that sails through most of the set is not separating a strong model from a weak one, and the data is worth less.

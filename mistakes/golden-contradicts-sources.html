The golden states something its own sources contradict

fails the task
Golden Solution - Artifact Completeness
1

What the issue is

A figure, a time, a mapping or a placement written into the golden that differs from what the photographed page, the log or the message thread it came from actually says. Or a sentence of prose inside the golden stating a total or a count the rest of the same page disagrees with, usually one that was true at an earlier turn. The artifact reads well and every graded column around it is right, which is why it survives to submission.

2

Why it matters, and what the project expects

The golden is the reference every subjective rating and the pairwise comparison are scored against, so a wrong value in it is graded as correct and a run that reads the source properly is marked down. Where a criterion grades the same detail, either your golden fails it or, if the criterion was written from the golden, a correct run does.

Including the values no criterion happens to grade. Those are where this hides.

QC specGolden Solution - Artifact Completeness
One or more files named in the prompt are missing or misnamed in golden/, a required content rule is unsatisfied, or the golden asserts a finding the inputs do not support.

The last clause is this error.

3

How to recognise it in your own task

Take every value the golden asserts that no criterion grades and point at the source line it came from. Then search the golden for every sentence containing a total, a count or a recommendation and check it against the tables on the same page.

4

Real tasks where this happened

Two real tasks in this project are carrying it. They are evidence that it is real and something to practise spotting it on, not a second version of the rule. Open one and it expands here, with the point on the left and the task's own fields on the right. Escape closes it.

5

What to do instead

Before you complete the conversation, get the model to fix it with a cleanup turn in the user's voice that points at the area, never at the value: “the totals at the top don't match the statement I sent” is a hint, “the total is $1,240” is a leak. Then check every place the value appears, not only the first, and reread any paragraph written at an early turn against the page as it stands now.

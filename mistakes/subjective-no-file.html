All mistakes · Section 6 · The subjective block

Subjective criteria that never name the file

costs points
Rubric Criteria - Subjective Block Scope
1

What the issue is

The block describes page features without saying which artifact carries them: the page, the body, the commitments table, monument cards. Typically one or two criteria at the top name the file and the rest do not.

2

Why it matters, and what the project expects

The evaluation target only says Final Answer Artifact, not which file. Once a task ships two deliverables, or a revision turn produces a second file, “the table” or “each scene” stops identifying anything, and two graders can score the same run against different files. With a single deliverable the file is implied, and the QC appendix accepts a criterion that leaves it out as long as another criterion checks the file exists. Naming it anyway costs nothing, and it survives a revision turn that adds a second file.

Attempter Guidelines5.1 Rubric Fundamentals
Self-contained: A reviewer should be able to rate the criterion using only the criterion itself and its assigned evaluation target, without reopening the prompt, input files, or another rubric. Include the exact expected value, filename, classification, decision, or other fact needed to determine whether it is Present or Not Present.

The filename is on that list whenever the reviewer needs it to know which file to rate, and 8.1 Writing Subjective Rubrics applies all of 5.1 Rubric Fundamentals to the subjective block exactly as written.

Attempter Guidelines8.1 Writing Subjective Rubrics
Anchor each criterion to one identifiable element and one visible property: Point to something that can clearly be located in the artifact, then evaluate a single observable characteristic of it. The element makes the criterion self-contained by telling the reviewer where to look.

Where a task ships more than one file, the filename is part of telling the reviewer where to look.

3

How to recognise it in your own task

List the files the task ships. If there is more than one, read down the subjective block: every criterion has to contain one of those filenames, and any row without one is this error.

4

Real tasks where this happened

One real task in this project is carrying it. It is evidence that it is real and something to practise spotting it on, not a second version of the rule. Open it and it expands here, with the point on the left and the task's own fields on the right. Escape closes it.

5

What to do instead

Open each one with “In <filename>,”. That is the entire fix.

Where the issue shows up here

Why that is wrong
The archive holds four files: a walkthrough video, a manifest CSV, a notes file and a transcript. Criteria 1 and 4 say "scene", so a grader can guess they mean the video. Criteria 2 and 3 grade pass and fail marks and table columns, and the notes file carries its own album tables with check marks, so two graders can score the same row against different files.
What it should have said
"In move_walkthrough.mp4, passed and failed outcomes are distinguished by colour or a mark, not by wording alone." The same opening clause on every row settles which file each one grades.

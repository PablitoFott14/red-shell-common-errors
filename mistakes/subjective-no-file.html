All mistakes · Section 6 · The subjective block

Subjective criteria that never name the file

costs points
Rubric Criteria - Subjective Block Scope

What the mistake is

The block describes page features without saying which artifact carries them: the page, the body, the commitments table, monument cards. Typically one or two criteria at the top name the file and the rest do not.

How to recognise it in your own task

Search the deliverable's filename across the subjective block and check every criterion returns a hit.

What to do instead

Open each one with “In <filename>,”. That is the entire fix.

Why it costs you

On a task shipping one artifact nothing goes wrong, which is why it keeps getting through. The cost lands the moment a task ships two deliverables, or a revision turn produces a second file: the body stops identifying anything and two graders score the same run against different files. It is one clause.

What the project says

The rules this breaks, quoted from the documents in Project Resources. Section titles are the ones printed in the document, so you can go and read the whole thing around them.

Attempter Guidelines5.1 Rubric Fundamentals
Self-contained: A reviewer should be able to rate the criterion using only the criterion itself and its assigned evaluation target, without reopening the prompt, input files, or another rubric.

Section 8.1 opens by saying all of 5.1 applies to the subjective block exactly as written.

Attempter Guidelines8.1 Writing Subjective Rubrics
Anchor each criterion to one identifiable element and one visible property: Point to something that can clearly be located in the artifact, then evaluate a single observable characteristic of it. The element makes the criterion self-contained by telling the reviewer where to look.

The filename is part of telling the reviewer where to look.

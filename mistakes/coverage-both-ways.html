All mistakes · Section 4 · A rubric that separates two runs

A requirement nothing grades, and a criterion nothing asked for

fails the task
Rubric Criteria - Overall Rubric Quality

What the project asks for gl §5.1 · spec · Rubric Criteria - Overall Rubric Quality

Every requirement a prompt states needs a criterion that owns it, and every criterion needs a sentence in a turn that asks for it. Missing Criteria and Incorrect Criteria are the two halves of the same check, and both count Major when the requirement is critical to the turn.

What the mistake is

Coverage fails in both directions. A requirement stated in a prompt that no criterion checks — most often the nothing-else half of an instruction. And a criterion requiring behaviour no turn requested, usually invented while writing the rubric against the golden instead of against the prompt.

How to recognise it in your own task

Walk the prompts line by line and write down which criterion owns each requirement. Then walk the criteria and point at the sentence in a turn that asks for each one. Anything with no partner on either pass is a finding.

What to do instead

Write each criterion from the prompt, then check it against the golden — never the other way round. Where an instruction has a nothing-else half, write the closure criterion: X consists only of A, B and C.

Why it costs you

An ungraded requirement means a run can do the wrong thing and still pass the whole set, which is exactly the failure the rubric existed to catch. A criterion nobody asked for does the reverse: it punishes a run for doing what the user actually said. Both are Major when the requirement is critical to the turn, and the second hides, because the golden often passes it by accident.

Why it is wrong
A run that reads every thread, corrects every divergent rule and ships the right runbook without a Sources line fails this criterion for doing precisely what was asked. The golden passes only because its runbook happens to end with a Sources line naming the channel. What it should have said
Delete the criterion, and delete that clause from milestone 11, keeping divergent rules replaced. The thread-derived rules themselves stay graded by the criteria that already cover them.

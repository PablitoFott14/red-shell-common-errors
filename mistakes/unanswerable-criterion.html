Rubric Criteria - Incorrect / Underfitting / Overfitting

What the mistake is

Four shapes of the same defect. Pinning an exact figure the source leaves open. Locking one of several defensible answers when nothing states the rule that picks it. Grading which route a value came from when two sources carry it. Scoping to a step or section, then requiring values that live elsewhere. And the mirror image: a criterion so loose that a run carrying the right answer plus the wrong ones still passes.

How to recognise it in your own task

For every exact value, name the line, frame or field it comes from. For every criterion naming one item as the answer, ask whether the prompt or the inputs state the rule that picks it. For every criterion that names a step or section, go to that exact moment in your golden and confirm the values are visible there. Then read each one back and ask what wrong run still passes.

What to do instead

If you cannot name the source, grade the pattern instead of the value. Where several answers are defensible, add the clause that forces the choice or grade the shape of the answer. Where two sources carry a value, grade that it was retrieved, not which door it came through. Where a run with an extra row survives, add the bound: exactly, only, between.

Why it costs you

The rubric exists to separate a correct run from an incorrect one. A criterion a correct run cannot satisfy marks down the readers who did the work, and it usually catches your own golden, because the golden followed the evidence while the criterion followed your memory. A criterion with no ceiling costs the distractors the task was built around nothing.
